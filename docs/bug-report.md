## Severity Guide

| Severity | Meaning |
|---|---|
| Critical | App crashes, or login does not work at all |
| High | A main feature is broken (add, edit, delete task) |
| Medium | Works, but with wrong behaviour (filter shows wrong tasks) |
| Low | Small issue (spelling, alignment, colour) |

## Bug Status

Open → In Progress → Fixed → Verified (tester re-tests it) → Closed

## Who to report to

| Problem area | Person |
|---|---|
| Screens, buttons, layout | Archit (frontend) / Suwaid (UI/UX) |
| Login, saving, "Request failed" errors, API responses | Adwaith (backend) |
| Wrong or missing data in tables | Shravan (database) |

Tip: press **F12** in Chrome → **Console** tab, and copy any red error into the bug's Actual Result.
